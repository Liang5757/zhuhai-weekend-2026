景点速查

缩略图为景点示意；以文字说明、门票范围为准。

爱情邮局与灯塔

在海边开启一天。拍灯塔、看沙滩，想寄明信片就顺路进店。

建议 45–60 分钟公共区域 ¥0

珠海渔女与香炉湾

渔女拍照后，到城市阳台吃午饭。沙滩漫步不赶路，累了就坐下。

含午餐约 2–3 小时公共区域 ¥0

野狸岛与日月贝

沿岛边散步，看双贝壳建筑从白天进入夜色，晚餐放在海韵城。

建议 2–3 小时公园 / 外观 ¥0

北山村与北山大院

看老巷与杨氏大宗祠外观，在庭院喝杯咖啡；午餐后回酒店换衣。

建议 2–2.5 小时街区 / 外观 ¥0

每日安排

建议时间表；车程、天气与婚礼签到按实际调整。

10/30周五

深圳 → 珠海 → H1入住

  • 18:00
    南山晚饭，带行李及赴宴衣服。
  • 19:30班
    深大A3右转歌文西饼门口上，红山－恒星园下；建议19:10到站。
  • 19:52备选
    深大A3左侧黄色客运停靠点上，香洲区府下；建议19:30到站。
  • 下车后
    打车去H1情侣中路汉庭，周五、周六连住。提前告知前台晚到。

两班截图价均16.8元；预计到达时间未提供，不能只按发车时间判断抵达先后。

31OCT / 周六

沿海一路向北。

  • 09:30
    酒店出发，打车到爱情邮局，早餐自行就近解决。
  • 10:15–12:15
    爱情邮局 → 珠海渔女，短段步行，怕晒可坐车。
  • 12:30–15:00
    城市阳台午餐，香炉湾看海与休息。
  • 15:30–19:30
    打车到野狸岛，逛日月贝与海韵城，晚餐后回酒店。

不要求全程走路。日月贝灯光以当日安排为准，不预设固定灯光秀。

01NOV / 周日

北山咖啡，晚间相聚。

  • 09:00
    退房，带行李打车到湾仔酒店寄存，暂留40–60分钟。
  • 10:30–13:00
    北山村 → 杨氏大宗祠外观 → 北山大院，午餐与咖啡。
  • 14:00后
    回湾仔酒店办理入住，洗澡、休息、换衣。
  • 16:30左右
    打车到华发喜来登，车程暂留10–20分钟；签到时间按请柬。

先确认酒店可寄存；不预设上午能拿到房间。遇拥堵或婚礼提前，删减北山行程。

02NOV / 周一 · 暂定

吃完早餐，再回深圳。

  • 08:00
    早餐、收拾行李，不再增加景点。
  • 09:00左右
    按返程票退房，打车去票面上车点。
  • 返程
    乘大巴回深圳，之后各自回家。

这是工作日。若需要周一上班，请先调整返程安排，不建议默认婚礼后能赶上末班车。
