# 珠海有约

2026-10-30 晚至 2026-11-02 上午（返程暂定）的珠海同行旅行方案。

- 静态 HTML / CSS / JavaScript，无构建依赖。
- 每间每晚住宿预算不超过300元；候选酒店指定日期价格与房态未确认。
- 路线图使用 Esri World Street Map 底图截图，标注具体候选酒店、景点、规划路线及距离，不能代替实时导航。
- 景点轮廓为原创SVG示意图。
- 费用计算为预算协商工具，非预订或报价服务。
- 驾车里程来自OSRM，步行来自FOSSGIS/OSM；直线距离单独标注。
- 坐标、原始坐标系、来源和道路规划结果见 assets/route-data.json。
- 页面不设封面，首屏展示行程摘要、地图与距离表。
- 来源及核对日期见网页底部。
